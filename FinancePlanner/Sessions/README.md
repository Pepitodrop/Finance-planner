# Sessions

Session/handoff notes are created **only** when a session leaves behind important context that would otherwise be difficult to reconstruct:

- unfinished multi-step work
- a difficult bug investigation
- provider verification work (GoCardless/PayPal/Google/HF live-verification steps)
- a deployment incident
- a migration
- a security investigation
- a major architectural refactor

Do **not** create a verbose note for every conversation, and do not write full conversation logs.

## Naming

`YYYY-MM-DD - Short Topic.md`

## Contents (only these — no transcripts)

- goal
- important findings
- decisions
- current state
- verification performed
- unresolved issues
- exact next steps
